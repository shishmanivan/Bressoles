# Статистика рыночных бросков

Собирается автоматически с момента установки этой версии. Старые броски восстановить нельзя.
Файлы создаются в рабочей папке игры при первом случайном рыночном броске:

- `MarketRolls.csv` — общий непрерывный журнал, одна строка на случайный результат одной акции. Столбец `Профиль` позволяет отдельно выбрать любой слот профиля. У A/B/C одного рыночного броска одинаковый `БросокID`.
- `MarketRollSummary.csv` — автоматически обновляемая сводка, общая (`Выборка = Общая`) и отдельно для каждого профиля (`Выборка = Профиль`, номер в столбце `Профиль`).

Оба файла — CSV с разделителем `;` и UTF-8 BOM, их можно открыть в Excel. Журнал общий для всех профилей, не сбрасывается при смене профиля или запуске нового забега. Профиль обозначается номером слота; переименование не меняет его статистику. Повторное использование того же слота продолжает его историю.

## Что считается броском

Записывается именно выбранный генератором исход: рост, падение или флет (неизменная цена), вероятность этого исхода и все три вероятности с учётом действующих модификаторов. Также сохраняются случайное число на шкале от 0 до 100, время UTC, уровень, раунд, день и признак тестового режима.

Гарантированные рост, падение и флет, в том числе распределения с единственным возможным исходом, исключаются. Исключение действует на конкретную акцию: если Insider гарантирует рост C, случайные A и B остаются в журнале. Дополнительные движения от карт не считаются отдельными рыночными бросками. Если Blue Chips отменяет принудительное падение и игра вновь выбирает случайный исход, этот случайный бросок учитывается с изменёнными вероятностями.

Фиксация происходит до анимации, ограничения минимальной цены и последующих реакций карт. Например, выпавшее падение при минимальной цене остаётся **падением** в журнале, даже если цена физически не снизилась. Это нужно для проверки генератора случайных исходов. Тестовый режим игры тоже учитывается, поскольку использует тот же случайный бросок; он отмечен в журнале. Сводка включает оба режима.

## Как читать сводку

Для начала выберите `ВероятностьГруппы% = Все`: на каждую акцию представлены три исхода. `СлучайныхБросков` — число случайных бросков этой акции, `Фактически` — число выпадений указанного исхода. `Ожидалось` — сумма вероятностей этого исхода **по всем** подходящим броскам, а не только по успешным. Например, два броска с шансами роста 50% и 60% дают ожидаемое число ростов 1,1 и ожидаемую частоту 55%.

`Фактически%` и `Ожидалось%` сравнивают частоты, `РазницаПП` — их разница в процентных пунктах. Остальные строки группируют броски по точной вероятности конкретного исхода: например, все броски C с шансом роста 50%, включая те, где рост не выпал. Строки `Все` и строки отдельных вероятностей перекрываются — их нельзя складывать между собой. Три исхода тоже используют один и тот же набор бросков акции.

Отклонение само по себе не доказывает, что генератор работает неправильно; сводка даёт наблюдения и математическое ожидание для дальнейшей проверки.

Журнал — первичный источник. Если Excel заблокировал перезапись сводки, сохранённые броски остаются в журнале; после закрытия файла сводка восстановится при следующем случайном броске. Её также можно пересоздать из папки игры командой `python market_roll_stats.py`. Ошибки записи выводятся в журнал ошибок приложения.
