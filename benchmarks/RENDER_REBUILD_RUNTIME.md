# Длинные прогоны и время анимаций

Это отдельные прогоны с обработчиком пустого ввода; они не заменяют основное сравнение одинаковых кадров. Числа p95 — медианы трёх прогонов.

## Полный и частичный показ

120 кадров × 3 прогона на сцену. Пересборка повреждённых областей включена в обоих вариантах; меняется только вызов SDL display.

| Размер | Сцена | flip p95, мс | update(rects) p95, мс |
|---|---|---:|---:|
| 1366×768 | static | 12.52 | 12.02 |
| 1366×768 | jump | 15.49 | 13.75 |
| 1920×1080 | static | 15.74 | 14.53 |
| 1920×1080 | jump | 18.57 | 17.78 |
| 3840×2160 | static | 38.64 | 37.31 |
| 3840×2160 | jump | 53.37 | 40.77 |

Оставлен полный flip: в целевом 1080p выигрыш p95 одного прыжка около 4%, меньше наблюдаемой вариативности. На 4K частичный показ помогает сильнее, но не достигает бюджета 16,7 мс. Полный путь проще при смене страниц, восстановлении окна и модальных переходах.

За 120 кадров прыжка: 0 загрузок файлов, 0 вытеснений, 0 снимков plain Surface. На первом цикле появляются ещё 1–2 варианта текста и один изображения из-за округления границ; затем повторные циклы используют те же рецепты/варианты. Неподвижная сцена прогревает только исходную позицию.

## Последовательное завершение хода

600 кадров, Clock.tick(60), настоящий SDL и реальное время. Длительность включает завершение эффектов и переходов руки. FPS означает частоту цикла, а не измеренную частоту физической развёртки.

| Размер | Ход до → после, мс | p95 до → после, мс | FPS до → после |
|---|---:|---:|---:|
| 1366×768 | 7376 → 6424 | 39.80 → 17.82 | 34.2 → 59.5 |
| 1920×1080 | 7618 → 6416 | 55.63 → 17.27 | 21.4 → 59.1 |

## Прыжки по реальным часам после возобновления работы

240 кадров, Clock.tick(60), три прогона. Сохраняем каждый прогон: скорость исполнения резко изменилась во время этой серии. Причина изменения нагрузки/производительности машины не установлена; медленные прогоны не отброшены.

| Размер | Прогон | p95 кадра, мс | FPS | Длительность прыжка min / median / max, мс |
|---|---:|---:|---:|---:|
| 1366×768 | 1 | 15.42 | 60.5 | 337 / 340 / 348 |
| 1366×768 | 2 | 14.58 | 60.1 | 334 / 337 / 349 |
| 1366×768 | 3 | 48.94 | 32.7 | 336 / 343 / 368 |
| 1920×1080 | 1 | 53.25 | 26.4 | 334 / 355 / 390 |
| 1920×1080 | 2 | 58.10 | 23.8 | 335 / 354 / 418 |
| 1920×1080 | 3 | 69.53 | 24.9 | 335 / 354 / 463 |

Проверка целевого p95 ≤16,7 мс в 1080p **не считается завершённой**: короткая серия укладывается, более длинные и повторные — не всегда. Для приёмки нужен повтор на целевом ноутбуке с зафиксированными питанием, загрузкой ОС, монитором и DPI. Растягивания логики на число кадров нет; момент регистрации завершения ограничен фактическим интервалом обновления.

Каждый цикл: пауза, колода, закрытие, 1920×1080, возврат к 1366×768, изменение Turns/цены. Между циклами собирается мусор.

Это ограниченная проверка циклов интерфейса, не многочасовой прогон всех боссов/раундов. Повторные настоящие эффекты хода проверены отдельной серией выше. Память исходных ресурсов входит в RSS.
