# Level card fonts

- `BodoniModa-ExtraBold.ttf`: static instance of Bodoni Moda, weight 800,
  optical size 48, generated using fontTools from
  https://github.com/google/fonts/blob/main/ofl/bodonimoda/BodoniModa%5Bopsz%2Cwght%5D.ttf
- `OldStandard-Regular.ttf`: Old Standard TT Regular, from
  https://github.com/google/fonts/blob/main/ofl/oldstandardtt/OldStandard-Regular.ttf

Both fonts are bundled under the SIL Open Font License. Their respective
license files are included in this directory. No font installation or network
connection is required to run the game.
